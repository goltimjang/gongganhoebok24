# 고객 후기 기능 설치 안내

고객이 홈페이지에서 후기를 남기면 **승인 절차 없이 바로 홈페이지에 표시**됩니다.
닉네임 또는 익명으로 남길 수 있고, 사진은 3장까지 첨부됩니다.

저장할 공간은 어딘가에 반드시 필요합니다. 아래 둘 중 **하나만** 고르면 됩니다.
**A안(Supabase)을 권합니다.** 스프레드시트를 쓰지 않고, 설정값 두 개만 복사하면 끝납니다.

---

## A안. Supabase (권장)

### 1. 프로젝트 만들기
1. https://supabase.com 접속 → **Start your project**
2. **Continue with GitHub** 로 로그인 (이미 쓰는 GitHub 계정 그대로)
3. **New project** → 이름 `areaclean24`, 비밀번호는 아무거나 정해 적어두기, 지역은 `Northeast Asia (Seoul)`
4. 2분 정도 기다리면 준비가 끝납니다

### 2. 저장소 만들기
1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. 이 폴더의 `supabase-setup.sql` 내용을 전부 붙여넣고 **Run**
3. `Success` 가 나오면 완료

### 3. 설정값 두 개 복사
1. 왼쪽 아래 **Project Settings → API**
2. **Project URL** 과 **anon public** 키를 복사

### 4. 홈페이지에 붙여넣기
`js/review-config.js` 를 열어 두 곳만 채웁니다.

```js
PROVIDER: "supabase",
SUPABASE: {
  URL: "https://여기에-복사한-주소.supabase.co",
  ANON_KEY: "여기에-복사한-anon-키",
  ...
}
```

저장하고 배포하면 바로 작동합니다.

### 후기 관리
- 왼쪽 메뉴 **Table Editor → reviews** 에서 남겨진 후기를 볼 수 있습니다.
- 지우고 싶은 후기는 그 줄을 선택해 삭제하면 홈페이지에서도 사라집니다.
- 지우지 않고 숨기고만 싶으면 `hidden` 값을 `true` 로 바꾸면 됩니다.

## B안. 구글 스프레드시트 (앱스 스크립트)

구글 시트에 후기를 모으고 싶을 때 쓰는 방법입니다.

1. 구글 드라이브에서 스프레드시트를 하나 만듭니다.
2. **확장 프로그램 → Apps Script** 에서 `review-backend.gs` 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 웹 앱**, 실행 주체는 **나**, 액세스 권한은 **모든 사용자** 로 배포합니다.
4. 나온 주소를 `js/review-config.js` 에 넣고 `PROVIDER` 를 `"gas"` 로 바꿉니다.

```js
PROVIDER: "gas",
GAS: { ENDPOINT: "https://script.google.com/macros/s/...../exec" }
```

시트에서 `상태` 열을 `숨김` 으로 바꾸면 그 후기는 홈페이지에서 내려갑니다.

## 자동으로 막아주는 것들

승인 절차가 없는 대신 아래는 자동으로 걸러집니다.

- 광고성 단어(도박·대출·성인 등)와 욕설이 들어간 글
- 본문에 들어간 **링크와 전화번호** (홍보 글 차단)
- 자동 등록 프로그램(봇)이 채우는 숨은 입력칸
- 같은 브라우저에서 **3분 안에 반복 등록**
- 10자 미만의 글, 사진 4장 이상, 1000자 초과

## 그래도 확인이 필요합니다

승인 없이 바로 올라가므로, **가끔 들어가서 확인해 주세요.**
문제되는 글은 위 관리 화면에서 지우면 홈페이지에서 즉시 사라집니다.
