# 고객 후기 기능 설치 안내

홈페이지에서 고객이 직접 후기를 남기고(닉네임 또는 익명, 사진 최대 3장),
사장님이 **승인한 후기만** 홈페이지에 표시되는 기능입니다.

- 서버 임대료: **0원** (구글 계정만 있으면 됩니다)
- 후기 보관 장소: 구글 스프레드시트
- 사진 보관 장소: 구글 드라이브

## 1. 스프레드시트 만들기

1. 구글 드라이브에서 새 **스프레드시트**를 만듭니다. 이름은 `공간회복24 후기` 로 합니다.
2. 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.

## 2. 스크립트 붙여넣기

1. 열린 편집기의 기존 내용을 모두 지웁니다.
2. 이 폴더의 `review-backend.gs` 내용을 전부 붙여넣고 저장합니다.

## 3. 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴 → **웹 앱** 을 선택합니다.
3. 설정값
   - 설명: `후기 접수`
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** 를 누르고 권한 승인을 진행합니다.
   (`이 앱은 확인되지 않았습니다` 화면이 나오면 **고급 → 이동** 을 누릅니다.)
5. 마지막에 나오는 **웹 앱 URL** 을 복사합니다.
   `https://script.google.com/macros/s/...../exec` 형태입니다.

## 4. 홈페이지에 주소 넣기

`js/review-config.js` 파일을 열어 ENDPOINT 에 복사한 주소를 붙여넣습니다.

```js
window.REVIEW_CONFIG = {
  ENDPOINT: "https://script.google.com/macros/s/...../exec",
  ...
};
```

저장하고 배포하면 후기 작성 폼이 홈페이지에 나타납니다.
**주소를 넣기 전까지는 작성 폼과 고객 후기 목록이 화면에 표시되지 않습니다.**

## 5. 후기 승인하는 방법

고객이 후기를 남기면 스프레드시트에 한 줄씩 쌓입니다.

| 열 | 내용 |
|---|---|
| A | 접수일시 |
| B | 닉네임 (비우면 익명) |
| C | 서비스 |
| D | 별점 |
| E | 내용 |
| F | 사진 주소 |
| G | 메모 (사장님 자유 기록) |
| H | **상태** |

**H열(상태)** 을 `승인` 으로 바꾸면 홈페이지에 표시됩니다.
`대기` 나 `보류` 로 두면 표시되지 않습니다. 지우고 싶은 후기는 행을 삭제하면 됩니다.

## 스크립트를 고친 뒤에는

내용을 수정했다면 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포** 를 눌러야
변경 내용이 반영됩니다. 주소는 그대로 유지됩니다.

## 참고

- 광고성 글이 올라와도 승인 전에는 홈페이지에 보이지 않습니다.
- 같은 사람이 3분 안에 여러 번 등록하는 것은 자동으로 막습니다.
- 사진은 홈페이지에서 자동으로 크기를 줄여 보내므로 용량 부담이 적습니다.
